🛠️ Maintenance Control Plane

Evidence and policy-based routing for security alerts and dependency updates

Repository Analysis

Data source

This dashboard reads a maintenance-rollup.public.json file produced by a scheduled, deterministic GitHub Actions workflow. No AI is involved in generating or classifying this data. The published file never contains exact Dependabot alert counts (see README.md); for exact counts, sign in and check a repository's own GitHub Security tab. A static sample fixture is also available below for reviewing the interface without live data.

⚪ Unavailable or unknown data

These coverage gaps mean a signal could not be verified — they are not evidence that a repository is insecure or non-compliant.
