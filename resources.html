What this view shows

This page reads a sanitized, aggregate resource rollup. It reports local computational measurements, provider-reported AI token categories, estimated remote inference energy where a licensed local factor dataset exists, and the quality of each measurement. It deliberately does not calculate a single sustainability score.

The published rollup contains no repository names, task labels, commands, filesystem paths, prompts, transcripts, session identifiers or private maintenance findings. Raw measurements stay local. See the resource privacy review.

Energy is reported in Wh, operational emissions in gCO2e, CPU time in CPU-seconds, elapsed time in milliseconds and memory in bytes. Missing data is shown as “—” and is not zero. A partial estimate is labelled as partial.
